# Bootstrap Toolkit

Bootstrap 5.3 live templates for HTML, React (JSX/TSX) and Vue in JetBrains IDEs (2025.2 and later).

| Group | Abbreviation | Inserts |
|---|---|---|
| Page | `bs5-starter` | Starter page: semantic structure (header, main, footer), light or dark theme, CSS, JS bundle and Bootstrap Icons from the CDN — list: theme |
| Layout | `bs5-col` | Responsive grid column (breakpoint and size) — list: breakpoint, size |
| Layout | `bs5-container` | Container (fixed, fluid or responsive) — list: type |
| Layout | `bs5-grid` | Grid: container, row with gutter and three equal columns — list: gap |
| Layout | `bs5-row-cols` | Responsive row: one column on phones, N columns from the md breakpoint — list: columns |
| Layout | `bs5-stack` | Stack: vertical or horizontal flexbox with gap — list: direction, gap |
| Components | `bs5-accordion` | Accordion with three items, the first one open |
| Components | `bs5-alert` | Alert — list: variant |
| Components | `bs5-badge` | Badge — list: color |
| Components | `bs5-breadcrumb` | Breadcrumb |
| Components | `bs5-btn-group` | Button group — list: variant |
| Components | `bs5-btn` | Button — list: variant |
| Components | `bs5-card-header` | Card with header and footer |
| Components | `bs5-card-link` | Card that is clickable as a whole (stretched link), with a real photo |
| Components | `bs5-card` | Card with a real photo (change the photo seed for a different image), title, text and button |
| Components | `bs5-carousel` | Carousel with real photos, indicators and controls |
| Components | `bs5-close` | Close button |
| Components | `bs5-collapse` | Collapse with its toggle button |
| Components | `bs5-dropdown` | Dropdown button with menu — list: variant |
| Components | `bs5-footer` | Footer with copyright and links |
| Components | `bs5-icon` | Bootstrap Icons icon (needs the Bootstrap Icons stylesheet, included in bs5-starter) — list: icon |
| Components | `bs5-list-group` | List group with an active item |
| Components | `bs5-modal` | Modal with its trigger button — list: dialog |
| Components | `bs5-navbar` | Responsive navbar with brand, links, dropdown and search — list: theme |
| Components | `bs5-offcanvas` | Offcanvas side panel with its trigger button — list: placement |
| Components | `bs5-pagination` | Pagination |
| Components | `bs5-placeholder` | Loading placeholder (skeleton) of a card — list: animation |
| Components | `bs5-popover` | Popover button (popovers must be initialized with JavaScript) |
| Components | `bs5-progress` | Progress bar — list: color |
| Components | `bs5-scrollspy` | Scrollspy: nav pills that follow a scrollable area |
| Components | `bs5-spinner` | Loading spinner — list: type, color |
| Components | `bs5-table` | Responsive table with header and rows — list: variant |
| Components | `bs5-tabs` | Tabs with their content panes |
| Components | `bs5-toast` | Toast in the lower right corner (show it with bootstrap.Toast) |
| Components | `bs5-tooltip` | Tooltip button (tooltips must be initialized with JavaScript) — list: placement |
| Content | `bs5-blockquote` | Blockquote with attribution |
| Content | `bs5-display` | Display heading (large, eye-catching title) — list: size |
| Content | `bs5-figure` | Figure: real photo with caption |
| Content | `bs5-icon-link` | Icon link: text with a Bootstrap Icons arrow that moves on hover |
| Content | `bs5-img` | Responsive image with a real photo — list: style |
| Content | `bs5-ratio` | Responsive embed (video) with a fixed aspect ratio — list: ratio |
| Forms | `bs5-check` | Checkbox with label |
| Forms | `bs5-floating` | Floating labels for email and password |
| Forms | `bs5-form-grid` | Form laid out with the grid (email, password, address, city, state, zip) |
| Forms | `bs5-form` | Form with email, password, checkbox and submit |
| Forms | `bs5-input-group` | Input group with a text addon |
| Forms | `bs5-radio` | Radio group with two options |
| Forms | `bs5-range` | Range input with label |
| Forms | `bs5-select` | Select |
| Forms | `bs5-switch` | Switch (toggle checkbox) |
| Forms | `bs5-validation` | Form with custom validation styles and feedback messages |

Every template works in HTML and Vue (`class`) and in JSX/TSX (`className`, `htmlFor`, self-closed tags,
`style={{...}}`, numeric props like `tabIndex={-1}`), so the React version compiles in TypeScript.

Type the abbreviation and press <kbd>Tab</kbd>. Start a new `.html` file with `bs5-starter` and every other
template renders styled right away.
