# Bootstrap Toolkit

Bootstrap 5.3 live templates for HTML, React (JSX/TSX) and Vue in JetBrains IDEs (2025.2 and later).

| Abbreviation | Inserts |
|---|---|
| `bs5-starter` | Full HTML page with Bootstrap CSS, JS and [Bootstrap Icons](https://icons.getbootstrap.com) from the CDN (HTML files only) |
| `bs5-btn` | Button, with a list of the Bootstrap colors, `link` and `outline-*` |
| `bs5-alert` | Alert, with a list of the Bootstrap colors |
| `bs5-badge` | Badge, with a list of the Bootstrap colors |
| `bs5-card` | Card with a real photo (picsum.photos), title, text and button |
| `bs5-navbar` | Responsive navbar with brand, links, dropdown and search |
| `bs5-modal` | Modal with its trigger button |
| `bs5-form` | Form with email, password, checkbox and submit |
| `bs5-table` | Responsive table (striped, hover, bordered, borderless, sm or dark) |
| `bs5-accordion` | Accordion with three items |
| `bs5-footer` | Footer with copyright (current year filled in) and links |
| `bs5-dropdown` | Dropdown button with menu, with a list of colors |
| `bs5-tabs` | Tabs with their content panes |
| `bs5-carousel` | Carousel with real photos (picsum.photos), indicators and controls |
| `bs5-toast` | Toast in the lower right corner |
| `bs5-spinner` | Loading spinner (border or grow), with a list of colors |
| `bs5-pagination` | Pagination |
| `bs5-breadcrumb` | Breadcrumb |
| `bs5-offcanvas` | Side panel with its trigger button (start, end, top or bottom) |
| `bs5-collapse` | Collapsible content with its toggle button |
| `bs5-list-group` | List group |
| `bs5-progress` | Progress bar, with a list of colors |
| `bs5-btn-group` | Button group, with a list of colors |
| `bs5-input-group` | Input with a text addon |
| `bs5-floating` | Floating labels for email and password |
| `bs5-popover` | Popover button (includes the one-line JavaScript to enable popovers) |
| `bs5-tooltip` | Tooltip button (includes the one-line JavaScript to enable tooltips) |
| `bs5-icon` | Bootstrap Icons icon, with a list of common icons to pick from |

Every template works in HTML and Vue (`class`) and in JSX/TSX (`className`, `htmlFor`, self-closed tags,
`style={{...}}`, numeric props like `tabIndex={-1}`), so the React version compiles in TypeScript.

Type the abbreviation and press <kbd>Tab</kbd>. Start a new `.html` file with `bs5-starter` and every other
template renders styled right away.
